## Mission Planning Features

| Feature | What it does for you |
|---|---|
| Visual mission planner | Builds waypoint, mapping, orbit, photo, and other supported mission types through the DroneLink app interface. |
| Reusable components | Lets you organize repeatable flight logic and adapt plans for new locations or assignments. |
| Mission previews | Helps you review planned paths and camera actions before operating the aircraft when your plan includes this capability. |
| Flight dashboard | Brings live flight information, video preview, mission controls, and status details into a focused operating view. |
| Connection checks | Makes it easier to confirm that DroneLink can connect to a supported drone before starting a mission. |

## Install DroneLink on Windows

Use the download badge above to obtain the Windows installer, save it to a trusted location, and run it. Before planning a flight, confirm that your aircraft and controller combination is supported.

## Built for Different Pilots

DroneLink is designed for recreational pilots building repeatable routes, educators demonstrating mission planning, independent operators capturing structured imagery, and teams coordinating mapping or inspection workflows.

## Common Questions

| Question | Answer |
|---|---|
| Is DroneLink free? | You can install DroneLink and test whether it connects to your drone without a login or paid plan, but creating and flying missions requires an account with an active plan. DroneLink does not provide a conventional free trial. |
| Which versions of Windows are supported? | Use a currently supported Windows release with up-to-date system and browser components. Check the built-in support resources before installation for the latest compatibility guidance. |
| How does DroneLink pricing work? | Hobbyist access is offered for recreational, educational, and nonprofit use, while Professional plans cover commercial workflows. Features, billing terms, and eligibility differ by plan, so review the current options shown in DroneLink before purchasing. |
| How do I connect DroneLink to a drone? | Power on the aircraft and controller, close any conflicting flight-control software, open DroneLink, grant the required permissions, and confirm that the aircraft name appears before opening the flight dashboard. |

## Security and Data Handling

- Keep account credentials private and use the sharing controls appropriate for each mission repository.
- Grant only the device and aircraft permissions needed for planning, connection, and flight operations.
- Review mission data, team access, and storage settings before using DroneLink for sensitive or commercial work.
